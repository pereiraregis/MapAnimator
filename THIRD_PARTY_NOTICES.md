## Rust timeline migration (v0.7.0)

The time, geometry, color and keyframe crates are now vendored verbatim under `rust/vendor/effectcraft`. Original source provenance and Git blob hashes are in `rust/vendor/effectcraft/UPSTREAM.json`; MIT license in that directory and `client/public/licenses/effectcraft-MIT.txt`. Runtime interpolation, effective easing, velocity, auto/continuous tangents and key icon semantics use this code directly. The MapAnimator egui panel adapts relevant interaction patterns; it is not the complete EffectCraft compositor UI.

Resolved Rust dependency license notices, including egui/eframe and their transitive dependencies, are distributed at `client/public/licenses/rust-dependencies.txt`, generated by `scripts/build-rust.mjs`. Some native/platform-specific dependencies are listed even though they are not in the web binary.

## Layer timeline additions (v0.8.0)

`rust/timeline-web/src/upstream_ui.rs` adapts `bar_color` and `trim_zones` from EffectCraft's `crates/ui-egui/src/timeline.rs` at the same pinned revision, with imports, visibility and formatting adjusted.
